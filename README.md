# 🎟️ Sistema de Reserva de Tickets para Eventos

## 📌 Descripción
Sistema completo de reserva de tickets para eventos con:
- **Frontend:** React + Vite + TailwindCSS
- **Backend:** Node.js + Express + MySQL
- **Autenticación:** JWT con roles (admin/user)
- **Docker:** Contenerización completa

## 🚀 Tecnologías
- **Frontend:** React 18, Vite 8, TailwindCSS 4, Axios, React Router 6
- **Backend:** Node.js 26, Express 5, MySQL 8.4, JWT, bcryptjs
- **DevOps:** Docker, Docker Compose
- **Pruebas:** Jest, Supertest
